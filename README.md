# OMNÉLYO — site vitrine

Site statique (HTML, CSS, JavaScript, sans dépendance) : accueil, pages des trois pôles, prise de rendez-vous, pages légales.

## À personnaliser

- `js/main.js`, bloc `CONFIG` en haut du fichier : adresse e-mail de contact, créneaux proposés, durée du rendez-vous, et `formEndpoint` (envoi des demandes par FormSubmit ; après activation, remplacer l'adresse e-mail par l'identifiant fourni).
- `index.html` : les champs surlignés en jaune des pages légales (statut, SIRET, adresse, hébergeur, TVA, médiateur).

## Mise en ligne

GitHub Pages : Settings → Pages → Source « Deploy from a branch » → branche `main`, dossier `/ (root)`.
